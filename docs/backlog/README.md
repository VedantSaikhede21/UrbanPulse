## Rules

- P0: Blocks launch or breaks core experience. Fix immediately.
- P1: Noticeable quality gap. Schedule next sprint.
- P2: Minor polish. Fix opportunistically.
- Ideas: Not committed. Record for later triage.

Every sprint, review P0 and P1 first. Never start new work while P0 items exist.
