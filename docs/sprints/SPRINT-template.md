## Objective

One sentence. What single thing will be different after this sprint?

### Forcing Questions

Before writing any feature, answer these three questions:

1. **Single user question** — What is the one user question this sprint answers? Every section must answer exactly one user question.
2. **One-hour scope** — Can the core value of this sprint be explained in one hour to a first-time contributor? If not, slice it.
3. **Kill List** — What should we REMOVE, not what should we ADD? Start every sprint by cutting.
