# Hero Principles

Permament rules for every UrbanPulse hero section.

---

## 1. Five-Second Comprehension

A first-time visitor must understand what UrbanPulse does in under 5 seconds — without reading more than one line of text.

**Test**: Show the hero to someone unfamiliar with UrbanPulse for 5 seconds, then hide it. They should be able to say "it's for ___."

## 2. Demonstrate, Don't Describe

The hero shows the product working. It does not rely on copy to explain the product category. Screenshots, interfaces, and live visualizations are preferred over descriptive text.

## 3. The Complaint Is the Protagonist

The citizen's complaint is the narrative backbone. AI agents are supporting cast — they exist to serve the complaint's journey from submission to resolution. Never lead with the technology; lead with the problem being solved.

## 4. Believable Demo Data

All sample data in the hero must feel realistic and internally consistent. Officer names should be plausible role-based labels. Timestamps should follow realistic patterns. Ward/department names should match the product's actual domain. Demo data that feels fake undermines trust more than no data at all.

## 5. Trust Through Interaction, Not Metrics

Trust is earned by showing the product working reliably — not through unverifiable claims ("99.99% uptime", "trusted by X agencies"). If a metric is shown in the hero, it must be:
- Real and verifiable, OR
- Anonymized but clearly real (e.g., "X complaints tracked today")

## 6. Maximum 5–7 Primary Visual Focal Points

Every element in the hero must earn its place. If it can be removed without changing the visitor's understanding, remove it. The hero must pass the "subtract test": remove each element one by one — if any removal doesn't hurt comprehension, it shouldn't be there.

## 7. Works for All Three Audiences

The hero must speak to three distinct readers simultaneously:
- **Citizen**: "Can I report my problem here?" — answer must be yes, immediately
- **Municipal Officer**: "Does this make my job easier?" — the value to the officer must be perceptible
- **Hackathon Judge**: "Why is this different from every other civic AI project?" — the differentiator must be visible

## 8. Emotional Arc

The hero should evoke a complete mini-journey:
1. **Recognition** — "This is my problem" (2 seconds)
2. **Understanding** — "Here's how it gets fixed" (5 seconds)
3. **Trust** — "This seems real" (10 seconds)
4. **Action** — "I know what to click" (immediate)

## 9. Visual Restraint

No decorative elements. Every color, shape, animation, and icon must serve comprehension or trust. If a visual can be described as "eye candy" rather than "functional interface element," remove it.

## 10. The "Tomorrow" Test

After visiting the landing page once, a person should be able to describe UrbanPulse to a colleague the next day from memory. If they can't, the hero hasn't done its job.
