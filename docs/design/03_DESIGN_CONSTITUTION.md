# UrbanPulse Design Constitution

Build the world's best civic AI experience.
Not just usable — memorable.

---

## Every Screen Must Satisfy

| Principle | Standard |
|-----------|----------|
| Understandable | Make sense in 5 seconds |
| Minimal | Nothing unnecessary |
| Premium | Feels crafted, not assembled |
| Fast | < 2.5s LCP, < 200ms INP |
| Accessible | WCAG AA, all input methods |
| Trustworthy | Government-grade tone, no hype |
| Citizen-friendly | Welcoming, not intimidating |
| Beautiful | Pleasing proportions, deliberate |
| Purposeful | Every element earns its place |

---

## Motion Philosophy

Never use animation because it looks cool.

Animation must:
- **Teach** — reveal relationships between elements
- **Guide** — direct attention to the next action
- **Explain** — show cause and effect
- **Delight** — reward interaction without distracting

If an animation doesn't serve one of these, remove it.

---

## Page Structure

Every page must have:
- **Primary Focus** — the one thing the user should look at first
- **Secondary Focus** — the next logical place to look
- **Visual Anchor** — a distinctive shape, image, or block that roots the layout
- **Breathing Space** — enough whitespace for each element to be seen clearly
- **Hierarchy** — size, weight, and color make importance obvious at a glance

Nothing decorative. Everything intentional.

---

## Storytelling

Every section should tell a story. Never become a list of cards.

Every page must have:
- **Beginning** — hook, context, why this matters
- **Middle** — how it works, evidence, details
- **End** — outcome, CTA, what happens next

---

## Interaction Principles

Every interaction should feel:
- **Alive** — responds within 100ms
- **Responsive** — matches the user's expectation
- **Natural** — follows physical logic (springs, easing)
- **Not robotic** — no jarring snaps, no delayed reactions

---

## Originality

Never copy.

- **Study** — understand why the best sites work
- **Understand** — extract the principle, not the execution
- **Improve** — make it fit UrbanPulse's unique purpose

The website should feel like Apple, Linear, Stripe, and Framer
without looking like any of them.

---

## One Thing Per Sprint

Every sprint improves exactly one measurable thing.

> If we could only improve one thing this sprint, what would it be?

All design, code, and QA serve that single objective. Everything else
is noise — defer it to the next sprint.

## Legacy

Every sprint should leave the project cleaner than it was before.
