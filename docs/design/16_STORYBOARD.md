# Storyboard

The emotional journey of a first-time UrbanPulse visitor.

Every section exists to move the visitor to the next emotional state.
If a section doesn't advance this story, remove it.

---

## Act 1: Arrival

| State | Emotion | Section | What the user thinks |
|-------|---------|---------|---------------------|
| 1 | 😕 Confused | Hero loads | "What is this?" |
| 2 | 🤔 Curious | Hero headline | "AI for civic issues? Let me see." |
| 3 | ✨ Intrigued | Hero animation + CTA | "This doesn't look like a government site." |

**Goal:** Hook the visitor in under 3 seconds.

---

## Act 2: Understanding

| State | Emotion | Section | What the user thinks |
|-------|---------|---------|---------------------|
| 4 | 👀 Engaged | Scroll starts | "OK, show me how it works." |
| 5 | 🧠 Learning | AI Pipeline | "It analyzes, deduplicates, prioritizes..." |
| 6 | 🤝 Trusting | Agent transparency | "I can see each agent thinking." |
| 7 | 📊 Impressed | City Health preview | "This would actually help my city." |

**Goal:** The visitor understands UrbanPulse completely.

---

## Act 3: Commitment

| State | Emotion | Section | What the user thinks |
|-------|---------|---------|---------------------|
| 8 | 💪 Confident | Trust signals | "Other cities use this. It's legitimate." |
| 9 | 🔥 Motivated | CTA section | "I want to see my city's data." |
| 10 | ✅ Converted | Report upload / Demo | "I'm in. Let me try." |

**Goal:** The visitor acts.

---

## Storyboard Rules

1. Every section maps to exactly one emotional state.
2. If two sections map to the same state, one is redundant — remove it.
3. The emotional progression is linear. Never ask the user to go backward.
4. Mobile visitors must experience the same emotional arc.
5. Reduced-motion visitors must still feel the progression through content, not animation.

---

## Verification

When reviewing a page, trace the emotional journey:

```
Visitor lands → [emotion] → Scrolls → [emotion] → ... → Clicks → [emotion]
```

If any step feels skipped or rushed, the section needs work.
If any section feels like filler, it should be removed.
