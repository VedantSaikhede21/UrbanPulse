# Product Review Checklist

> **Purpose**: Every section must answer exactly one user question. Run this checklist at sprint end for every new or changed section.
> **Source**: Extracted from `AGENTS.md` §Product Review.

---

## How to Use

1. Pick a section (e.g., Hero, Problem, Trust, Why Nine).
2. Answer all 9 questions for that section.
3. Mark **Pass** or **Fail** for each question.
4. If any question fails, fix the section before shipping.

---

## The 9 Questions

### 1. User's Thought

> **What is the user thinking when they see this?**

- Pass: The thought matches the section's intent.
- Fail: The user thinks something unrelated, confusing, or empty.

### 2. Intended Emotion

> **What emotion should they feel?**

- Pass: The emotion is identifiable (trust, curiosity, relief, urgency, hope).
- Fail: The emotion is unclear, absent, or inappropriate for the content.

### 3. Tomorrow's Memory

> **What do they remember tomorrow?**

- Pass: One single memorable takeaway.
- Fail: Nothing sticks, or they remember a distraction.

### 4. 30-Second Pitch

> **Can they explain UrbanPulse to a friend after 30 seconds?**

- Pass: After seeing this section, they could describe the product's value in one sentence.
- Fail: They'd stumble, use technical language, or say "it's like… but I'm not sure."

### 5. Disappearance Test

> **If this section disappeared, would understanding decrease?**

- Pass: Yes — the page would be incomplete without it.
- Fail: No — delete it.

### 6. Taste Benchmark

> **Would Stripe / Linear / Apple / Vercel / Framer ship this?**

- Pass: The execution would meet the standard of a top-tier product company.
- Fail: It looks generic, unfinished, or amateur by comparison.

### 7. Motion Purpose

> **Does every animation have a purpose?**

- Pass: Every transition, hover effect, and micro-interaction communicates something (state change, hierarchy, feedback).
- Fail: Animations exist "because we can" — decorative, distracting, or slow.

### 8. Wow Moment

> **Is there a single "wow" moment on the page?**

- Pass: The user encounters something that makes them pause and feel impressed or delighted.
- Fail: The page is competent but flat — no memorable peak.

### 9. Real Problem vs Filler

> **Is this solving a real user problem or filling space?**

- Pass: This section helps the user make a decision, understand the value, or take action.
- Fail: It exists because "every landing page has one" or to make the page longer.

---

## Scoring

| Score | Meaning |
|-------|---------|
| 9/9 Pass | Ship it. |
| 7–8/9 Pass | Fix failures before shipping. |
| ≤6/9 Pass | Don't ship. Redesign the section. |

---

## Example: Landing Hero

| # | Question | Verdict |
|---|----------|---------|
| 1 | What is the user thinking? | "They show a real complaint being tracked." — **Pass** |
| 2 | What emotion should they feel? | Relief and curiosity. — **Pass** |
| 3 | What do they remember tomorrow? | "The complaint that got resolved." — **Pass** |
| 4 | Can they explain to a friend? | "It's a system that tracks city complaints from report to fix." — **Pass** |
| 5 | Would understanding decrease? | Yes — the hero sets the entire context. — **Pass** |
| 6 | Would top companies ship this? | Yes — polished pipeline visualization, authentic data. — **Pass** |
| 7 | Does every animation have purpose? | Yes — waiting dots, resolution checkmark, self-draw line. — **Pass** |
| 8 | Is there a "wow" moment? | The waiting→resolved transition. — **Pass** |
| 9 | Real problem or filler? | Real — answers "what does this product actually do?" — **Pass** |

**Score: 9/9 ✅ Ship**
