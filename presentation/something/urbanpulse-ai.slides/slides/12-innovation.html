Why judges should look twice.

01
Multi-Agent DAG orchestration
LangGraph directed acyclic graph — 9 specialized agents run in parallel where independent, gated where sequential. Not a chained prompt.
02
Live SSE agent trace
Every agent's reasoning streamed to the browser via Server-Sent Events. Explainable AI you can watch — no black box for citizens or judges.
03
Trust & fraud scoring
Reputation model + spam signals + missing-media checks catch bad-faith reports before they clog the queue.
04
Spatial + semantic dedup
PostGIS ST_DWithin (50m) + embedding similarity — the same pothole reported 12 times becomes one ticket.
05
Explainable priority
Severity score is not a black-box number — Priority Agent surfaces the reasons (proximity to school/hospital, hazard class, description NLP).
06
Urban Health Score
Composite 0–100 metric per ward — proprietary weighting of resolution time, density, severity, SLA compliance. Actionable, not vanity.
07
SLA-first escalation
Every ticket carries a severity-based deadline. Escalation Agent triggers pulse alerts before public outrage, not after.
08
Docker-first horizontal scale
Containerized FastAPI + async workers + PostGIS scale-out. Ready for 10K reports/day with Celery + Redis when growth demands.
